# EjercicioProyectoTian
## Proyecto de una tienda a nivel local
### Este proyecto tiene como objetivo fortalecer el comercio local en el Valle de México mediante una plataforma digital que conecta directamente a productores locales con consumidores, facilitando la venta de productos artesanales, textiles tradicionales y artículos de alta calidad. La iniciativa busca preservar el conocimiento ancestral y el patrimonio cultural mediante la promoción de prácticas artesanales sostenibles. Además, integra servicios de logística de última milla a través de bicimensajeros, lo que permite una distribución eficiente, segura y ecológica. Con ello, se impulsa una economía circular, sustentable y socialmente responsable, fomentando el consumo de productos naturales y orgánicos, así como el transporte bajo en emisiones.

Se usa el tipo de metodología: SCRUM.
Se usa Trello para cronograma de tareas y Figma para guía visual de la plantilla de desarrollo.
